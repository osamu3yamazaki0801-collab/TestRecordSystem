# アプリケーション名
試験記録台帳

## 概要
- 目的
  - Webベースで制御ユニットのルーチン試験結果を登録したり、参照するデータベースソフト。
- 利用シーン
　- 試験結果の登録
　- 試験結果を探す
- 解決する課題
　- 試験結果の一元管理
　- 試験結果の検索スピード向上
- 主な機能
　-新規作成機能とこれまで作成したデータを検索機能

## 仕様
### 起動画面（ログイン）
-ユーザID、パスワードを入力を促す画面。
- ユーザID:toshiba
- パスワード:toshiba

### 新規登録
-「新規登録」ボタンを押下したとき
　以下の項目を入力できる画面を出して、画面の下に「登録」ボタンと「キャンセル」ボタンを用意する。
- 登録項目
  - 試験番号
  - 案件名
  - 製番
  - 登録日
  - 担当者
  - 試験結果

試験番号、製番は半角数字英字で20文字
案件名は日本語入力で30文字程度
登録日はyyyymmdd
担当者は日本語入力
試験結果はファイルを登録することができる

-「検索」ボタンを押下したとき
以下の項目を入力できる画面を出して、キー入力のあったら検索して、表形式で出力する。デフォルト時とか検索キーに何も入力がない場合はデータベース全てを出力する。
検索キーは以下できるようにする。
- 試験番号
- 製番
- 登録日
- 担当者

### 検索の仕様
キー入力があった時点、前方一致でヒットするものを表示する。
*はワイルドカードとして、正規表現で検索できるようにする。
